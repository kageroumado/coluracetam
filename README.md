# Coluracetam

Coluracetam brings the same Markdown preview to Finder’s spacebar and a live split editor, with document-wide selection and search. It also generates file thumbnails and exports PDF and HTML.

<a href="https://kagerou.glass/coluracetam/"><img src=".github/download.svg" alt="Download Coluracetam for Mac" width="360" height="80"></a>

![Coluracetam](.github/coluracetam-split.png)

## Highlights

- Read the same Markdown preview in Finder’s Quick Look and the app’s split editor.
- Select and search across the rendered document.
- Keep unsaved edits when files change in another editor.

<details>
<summary>Full feature list</summary>

- Finder Quick Look with the spacebar, plus generated file thumbnails.
- Live source/preview split with document-wide text selection and search.
- PDF and HTML export.
- Ordinary UTF-8 `.md` and `.markdown` files, with light and dark previews.
- Zoom with **⌘+**, **⌘−**, and **⌘0**.
- External-file reloads that preserve unsaved edits.

</details>
